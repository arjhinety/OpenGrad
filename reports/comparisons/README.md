# Comparisons

Rendered run-to-run comparisons, written by `opengrad compare <baseline> <candidate>`.

Empty. Comparisons in this project have been made inside the reports that needed them rather than
as standalone artifacts, and the authoritative per-checkpoint comparison is recorded machine-
readably in each run's `eval/` directory — for example
[`runs/m0_sft_canonical_v2_final/eval/dev/selection--dev.json`](../../runs/m0_sft_canonical_v2_final/eval/dev/selection--dev.json),
which holds the full behavioural vector for every checkpoint against the baseline.
