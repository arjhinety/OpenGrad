# Wikidata's licence, as read for P-UNANS-v2-constructed

- **Read:** 2026-10-01. The source is the project page `Wikidata:Licensing` at revision 2548950862 (saved
  2026-09-24T03:42:07Z): <https://www.wikidata.org/w/index.php?title=Wikidata:Licensing&oldid=2548950862>.
- **What it says, verbatim:**

  > All structured data (i.e. the main, Property, Lexeme, and EntitySchema namespaces) is released into the
  > public domain under [Creative Commons Zero](https://creativecommons.org/publicdomain/zero/1.0/).

- **What OpenGrad uses:** item and property data only (names, edition years, population years) from the main
  namespace. That is `wikidata-snapshot.json`, pinned in `punans-v2-constructed.manifest.json`. CC0 needs no
  attribution. OpenGrad names the source anyway.
