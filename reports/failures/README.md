# Failure analysis

Clustered failure output for evaluated runs. One directory per run, holding the per-category
breakdown produced by `opengrad failures <run_dir>`.

Populated for the B0 baseline. Absent for other runs because their evaluation reports carry the
failure discussion directly — see [`reports/M0_SFT_EXECUTION_REPORT.md`](../M0_SFT_EXECUTION_REPORT.md)
and [`reports/M0_CANONICAL_V2_FINAL_EVALUATION.md`](../M0_CANONICAL_V2_FINAL_EVALUATION.md).
